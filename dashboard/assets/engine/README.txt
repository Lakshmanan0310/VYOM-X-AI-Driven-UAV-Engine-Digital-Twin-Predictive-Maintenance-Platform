VRDE 2.2L Realistic Inline-4 GLB

This asset is a detailed representative CAD-style inline-four turbo piston/diesel engine visualization.
It is NOT proprietary VRDE production CAD. It is intended as the visual Digital Twin representation
for the simulated VRDE 2.2L aero-diesel telemetry in this prototype.

The model contains separately named components for dashboard highlighting, including Cylinder_1..4,
Turbo_* components, Oil_Sump*, Propeller_*, intake/exhaust components, oil filter and accessories.
